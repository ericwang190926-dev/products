# 包装刀版设计工具 · Dieline Studio

离线单文件网页工具：选盒型 → 按你们平时说的方式选用料（灰板/铜版纸/白卡/特种纸的克重，或瓦楞粗细）并填写产品放进去的内尺寸 → 自动生成刀版（刀线、压痕线、多印边、涂胶位置、尺寸标注；硬盒还带裱纸展开）→ 按面贴 Logo/图片/文字，并可指定烫金、局部UV、凹凸、激凸、逆向UV、覆膜等工艺 → 实时 3D 预览（可折叠动画、开盖，工艺会表现出来）→ 导出给供应商报价的 PDF/SVG/DXF/PNG。

**在线使用（可直接把链接发给别人）：** https://ericwang190926-dev.github.io/products/

也可以双击 `dist/index.html` 离线使用（所有 JS/CSS/three.js 已内联，无需联网）。更新网页上的版本：`npm run deploy`（会重新构建并发布到 GitHub Pages）。

## 盒型（25 种，参数化定义）
插舌盒：直插盒、反插盒、开窗插舌盒、挂钩插舌盒、粘口盒(四翼封口)
锁底盒：扣底盒(自动锁底)、插舌+快锁底(1-2-3底)、挂钩扣底盒、开窗扣底盒
礼盒/硬盒：天地盒、书型盒(磁吸翻盖)、抽屉盒(外套+内托)、封套盒、腰封
电商/展示/托盘：飞机盒(FEFCO 0427)、展示盒(PDQ)、托盘(四角粘合)、一体翻盖盒
异形盒：枕头盒、手提盒(屋顶盒)、六角盒、三角盒、八角盒
卡类：吸塑背卡(可对折开窗)、对折吊卡

新增盒型：在 `src/core/styles/` 写一个 `build(ctx)`（用 `Builder.add()` 添加面板，指定父面板与折线 `hinge`、折叠角度），并在 `styles/index.js` 注册即可；刀线/压痕线、出血、3D 折叠、缩略图全部自动生成。

## 尺寸和用料
默认按**外尺寸**填写（盒子外面量到的尺寸，单位 mm），工具会自动扣除纸板厚度算出里面能放多大产品（内尺寸）；也可以在高级设置里切回“内尺寸”填写。天地盒可选“鞋盒式（半盖）”或“全盖（天盖盖到底）”，书型盒可选“长边打开”或“短边打开”，开盒边的包边盖到盒底；刀版上用“磁铁位置”层标出内嵌磁铁（磁铁内嵌在灰板里，外面看不到），3D 默认不显示，可在“显示磁铁位置”里查看。

**封套盒内盒与内衬：**
- **封套盒**可直接搭配内盒一起展示与导出：可选 **灰板裱纸内盒**（灰板克重 + 铜版纸裱面，并自动生成内盒裱纸展开图）、**铜版纸折叠内盒**（单张铜版纸折成内托）或 **只要封套（无内盒）**。内盒尺寸按封套外尺寸减去板厚与缝隙自动计算，3D 预览默认半抽出展示（也可勾选“封套半透明”）。
- **内衬（天地盒、抽屉盒、书型盒、封套盒可选）**：支持 **EVA**（厚度、颜色、圆角槽/矩形槽/圆形孔及数量排布，出裁切平面图）、**吸塑**（透明/白/黑/植绒、凹槽深，出供模具厂参考的尺寸图）、**纸盒**（白卡/铜版纸折叠挖孔内托，出真实刀版）、**纸卡**（白卡/铜版纸冲孔纸卡，出真实刀版），尺寸自动适配盒内空间并在 3D 与 PDF 报价单中同步显示。

用料按销售日常说法选择，不必先知道“纸厚/卡力/FEFCO”这些词：
- **单层卡纸盒**：选 铜版纸 / 白卡纸 / 特种纸（珠光、触感、牛皮、棉纸、艺术纸），再选克重 150 / 157 / 200 / 250 / 300 / 350 / 400g（也可手填）。
- **灰板裱纸硬盒**（天地盒、书型盒、抽屉盒默认）：灰板 800 / 1000 / 1100 / 1200 / 1400 / 1600g，再选面纸（铜版纸或特种纸）克重。默认 1200g 灰板 + 157g 铜版纸。
- **瓦楞纸盒**（飞机盒默认）：选细瓦（E楞）/ 中瓦（B楞）/ 双瓦（BE楞）。

克重会按常见国内供应商对照表换算成板厚（例如 350g 白卡约 0.50mm，1200g 灰板约 1.9mm，157g 铜版纸约 0.14mm；灰板 1000g≈1.5–1.6mm、1400g≈2.2mm）。对照表写在 `src/core/materials.js`，是行业近似值，不是纸厂质检单。硬盒还会按板厚和约 15mm 包边自动出裱纸展开图。

## 包装工艺
整盒可选光膜 / 哑膜。局部工艺（可多选）可加在已放好的 Logo/文字上，或在盒面上画出一块区域：局部UV、凹凸（凸起/凹陷）、烫金、烫银、激凸、逆向UV。2D 刀版和 3D 预览都会显示；导出 PDF/SVG 时每种工艺单独一个专色图层（Foil_Gold、Foil_Silver、Spot_UV、Reverse_UV、Emboss、Deboss、Raised_Emboss），方便供应商出菲林/印版。

## 导出
- PDF：矢量刀版，图层(OCG)：Artwork / Glue / Bleed / Crease / Cut / Dimensions / Labels / Info，以及用到的工艺专色层。刀线为专色 `CutContour`，压痕线为专色 `Crease`。标题栏用简体中文写清盒型、内/外尺寸、用料克重和工艺（Noto Sans SC 字形以轮廓嵌入，不依赖对方电脑有中文字体）。图稿为 300dpi 内嵌图并按多印边裁切。
- SVG（分层，含工艺层）、DXF（R12，图层 CUT/CREASE/PERF/BLEED/GLUE/DIM）、平面效果 PNG、3D PNG、项目 JSON（可再打开）。
